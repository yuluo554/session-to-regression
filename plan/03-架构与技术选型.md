## 三、事件流 IR（M1 输出契约，M0 已定稿）

| 字段 | 类型 | 语义 | 纪律 |
|---|---|---|---|
| `source` | `"claude"` \| `"codex"` | 来源 harness | 集外值即报错（按**首行形态**判别，不按目录名） |
| `session_id` | str | 会话 id | 不得为空；合成值走白名单 |
| `seq` | int ≥ 1 | **源文件行号**（1-based） | 不是紧凑数组下标——行号可由日志复算，下标会随过滤漂移 |
| `source_offset` | int ≥ 0 | 该行在文件中的字节偏移 | 供锚点回溯 |
| `ts` | str | 日志自身的时间戳 | **全程不读时钟**；取不到落 `unknown` |
| `kind` | enum | `user_msg`/`assistant_msg`/`tool_call`/`tool_result`/`meta` | 集外值即报错 |
| `tool` | str | 工具名 | 取不到落 `unknown`，**不写空串** |
| `path` | str | 文件类工具的目标路径 | 仅文件类工具非空；同上 |
| `payload` | object | 归一后的关键字段（如 `old_string`/`new_string`/patch 文本） | 只放 JSON 可序列化的纯值 |

排序键 `(source, session_id, seq)`——三个分量都能从输入独立复算（K5）。
**版本指纹表当前为空**：M0 不宣称任何版本键名（R1–R3 未闭环），检测即显式报错。

## 四、技术选型与弃选理由

| 选型 | 决定 | 理由 / 弃选项 |
|---|---|---|
| 语言与版本 | Python ≥ 3.8 | 与本机（3.8.8/3.12）及 CI 矩阵一致；3.8 是底线，写法上禁用 3.9+ 语法与 `pathlib` 的 3.10+ 参数 |
| 运行期依赖 | **零第三方** | 「可离线复现」是可被审计的性质；因而自研 `tomlmini` 而不是引 `tomli`（代价如实声明：只支持子集，超集显式报错） |
| 配置格式 | TOML（`config/scoring.toml`） | 题面指定；用自研严格子集读取器解析，**读不懂就报错不回落默认值** |
| 测试框架 | pytest（dev extra） | 生成物也是 pytest；**运行期可选依赖**：缺 pytest → exit 3，不退化成 exit 0 |
| 交付形态 | 纯本地 Python CLI（无 GUI/无 exe） | 题面限定唯一形态；形态收敛避免"名义支持" |
| 并发 | 不用 | 确定性优先：并发会让"同输入双跑逐字节一致"失去可验证性 |
| git | 可选加速，**非依赖** | 本机实测 37 个改文件会话中仅 7 个在 git 仓库内；依赖 git 会让八成会话处理不了 |
| LLM | 不引入（弃） | 破坏"纯本地/可离线/零上传"定位，且生成结果不可证伪；候选断言由 diff 推断并标"需人工确认" |
| 多语言生成（弃，首期） | 只识别 `.mjs`/`.ts` | JS/TS 的框架与模块解析差异大，共用模板会变成"名义支持" |
| 自动改源码（弃） | 只写测试目录与临时副本 | 引入正确性责任与安全风险，且与 RED 验证的隔离原则冲突 |
| 用真实日志做基准（弃） | 一律合成会话 + 植入真值 | 真实日志含用户代码与 prompt，入库即破隐私红线；且严格样本仅 5 个 |

## 五、横切契约（M0 已落地，后续里程碑"动了会打挂测试"）

| 契约 | 落点 | 守门 |
|---|---|---|
| 唯一数值口径 | `config/scoring.toml` + 随包副本 | 两处逐字节相同；代码内零口径数值（≥100 整数字面量白名单双向核对） |
| 退出码语义 | `errors.EXIT_CODES` | CLI 契约测试 + 每条已交付命令的离线冒烟（bare + module 两形态） |
| 确定性写盘 | `serialize.write_*` | 同输入双跑/双写逐字节一致；无 CR；结尾单换行；原子写不留临时件 |
| 编码加固 | `stdio.ensure_utf8_stdio` + 子进程显式 `encoding` + CI `PYTHONUTF8=1` | cp1252 复现测试；EOL 门（`tools/fix_eol.py --check`） |
| 隐私（源码层） | 无网络依赖 | AST 导入门：`socket`/`ssl`/`http`/`urllib`/… 出现即红；入库文本零本机路径形态 |
| 文档-实物一致 | README | extras 双向对账、命令表 ⊆ 真实子命令、退出码表 ⊇ 全部语义、LICENSE 在场、package-data 真存在 |

## 六、风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 日志格式随 agent 版本演进 | 解析器静默错解 | 版本指纹表 + 显式集合；未知 → `unsupported_format`；本机实测为准，不猜测 |
| 未核对字段（R1–R3）混入判定路径 | 切分/还原全错且不自知 | 未核对字段只能落 `unknown` 或整条跳过；M1 先闭环再进 M2（K4） |
| 真实样本量小（5/29） | 结论不可统计 | 评测主体为合成基准 + 植入真值；真实样本只作演示与人工抽验 |
| 超大会话（831.6 MB 量级） | 内存爆掉 / 读锁死 | 逐行读取 + 行长上限 + 事件数安全阀（均在口径文件定义）；超限显式报错 |
| `old_string` 多处命中 | 还原出错的 before | `unresolved` 而非"任选一处"；不伪造上下文行 |
| 用户工作区被污染 | 数据损坏（最严重） | 验证在临时副本内进行；只写测试目录；不碰 git 索引；工具不做删除类动作 |
| 生成物含用户代码 | 隐私泄露 | 生成物默认只落本地；公开仓库只含合成基准；README 明写"不发送任何数据" |
| CI 首推暴露环境差异 | 发布期返工 | M0 起前置工程（eol=lf + 编码三层 + 退出码契约锁测试 + 双解释器实跑）；本地等价校验 + 干净安装面复核，缺口显式标注"待首推验证" |
