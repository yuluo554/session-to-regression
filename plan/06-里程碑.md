## M4 生成器（✅ 2026-10-17 完成）

**任务**：约定探测、AST 读签名、模板生成、docstring 证据锚点、候选断言；`s2r generate` 落地。

**DoD**：合成基准生成内容对账；同 episode **逐字节稳定**；`needs_manual` 有明确原因；
`assumed_convention` 显式标注；**不改任何源码**（断言目标仓库源码树哈希不变）。

**降级策略**：目标符号识别不到 → 不生成文件（宁缺勿造）；约定探测失败 → 保守默认 + 标注。

**命令**：`s2r generate <episode_ref> --repo <dir>`（或 `--out-dir`）

**可演示物**：一份生成的 `tests/regression/test_*.py`（带证据 docstring 与候选断言）。

**落地事实（回写，供下一棒与复核）**：

* **只有 `ok` 进生成路径**：没有修改前全文就读不出"修改前的签名"→ `partial`（片段）、
  `unresolved`（不任选）、`no_before_image` 一律只记原因、不产文件（`reconstruction_not_usable:<状态>`）；
  非 `.py` 的改动另有 `not_python`（真实会话抽验里这类占多数）；
* **候选断言只有一种推导形态**：`return <expr> if <cond> else <alt>`，且 `cond` 恰是被调符号的形参名、
  `alt` 是字面量；探测值取"与 `alt` 同型的假值"（假值才把守卫弄假）——推不出来就只给证据注释并标
  `needs_manual`（`assert_not_derivable` / `probe_not_derivable`），**不猜**；
* **逐 episode 结论**：一会话多 episode 各有独立结论，一个推不出来不影响另一个产出；
* **落点显式**：`--repo`（目标仓库根）或 `--out-dir`（隔离输出根），都不给 → exit 2；只写测试目录，
  源码树逐文件哈希不变（K11）；
* **stdout = 机读产物**（骨架内容 + 逐 episode 结论），stderr = 人读摘要。

**证据**：`src/s2r/generate.py`、`tests/test_generate.py` + `tests/test_generate_cli.py`、
基准生成层对账（`expect_generated`，10 样本全覆盖）+ 探活 `drop-candidate-assert`、
生成物 RED→GREEN 端到端语义核对（隔离临时目录内）、逐条留档见 [verify/README.md](verify/README.md) §M4。
