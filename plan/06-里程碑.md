# 06 里程碑（M0–M6：目标 / 任务 / DoD / 降级策略 / 命令 / 可演示物）

> **数值口径**：权重、阈值、超时、临时目录策略只在 `config/scoring.toml` 定义，本文件只引用。
> **未核对字段纪律**：M1 未闭环的 R1–R3 不得进入 M2 判定路径与 M4 生成路径（见 [04-模块详设.md](04-模块详设.md)）。

> 并列出等价物清单与缺口；M6 首推后按事实**追加**真实 run 结论（不改写历史措辞）。
> **收尾纪律**：每个里程碑 DoD 达成后，必须在本对话内写完下一棒的 `plan/HANDOFF-M<next>.md` 才允许结束

## M2 episode 切分

**任务**：语义词表读取（唯一来源配置）、切分状态机、确定性打分与阈值过滤、四类边界情形落定、
`scan` 输出附 `episodes[]`。

**DoD**：合成基准切分真值**逐例**对账（应切/不应切都算，含多 bug / 未修复 / 先成后败 / 仅提问）；
打分权重只读配置（改配置即改行为，测试锁死）；低分候选计入过滤统计而非静默丢弃。

**降级策略**：某类边界样本在合成基准里做不出来 → 在 `notes` 里声明 `missing_types`，**不假装覆盖**。

**命令**：`s2r scan ... --out events.json`（含 `episodes[]`）

**可演示物**：同一份合成日志 → episode 清单（含分数、状态、证据锚点）。

## M3 差分还原

**任务**：三级降级还原 + 置信度标注 + 磁盘文件可选对齐；`s2r reconstruct` 落地。

**DoD**：合成基准 before/after **逐字符**对账；三条降级路径各有样例；多重命中 → `unresolved`（不任选）；
无法对齐时如实降级；同一输入同一输出。

**降级策略**：磁盘文件已被改动 → 只用日志内证据；日志信息不足 → `unverified: no_before_image`（不伪造）。

**命令**：`s2r reconstruct <session> --out rec.json`

**可演示物**：一次修复的 before/after 文本（人读 diff 片段）。

## M4 生成器

**任务**：约定探测、AST 读签名、模板生成、docstring 证据锚点、候选断言；`s2r generate` 落地。

**DoD**：合成基准生成内容对账；同 episode **逐字节稳定**；`needs_manual` 有明确原因；
`assumed_convention` 显式标注；**不改任何源码**（断言目标仓库源码树哈希不变）。

**降级策略**：目标符号识别不到 → 不生成文件（宁缺勿造）；约定探测失败 → 保守默认 + 标注。

**命令**：`s2r generate <episode_id> --repo <dir>`

**可演示物**：一份生成的 `tests/regression/test_*.py`（带证据 docstring）。

**可演示物**：一条命令 → 目标仓库里多出一个**会红灯**的回归测试 + manifest 证据链。

## M6 发布（GitHub 公开仓库）

**DoD 三件套（缺一项即发布未达成）**
1. `git tag`（annotated）；
2. **GitHub Release 附产物**：源码 zip（手工上传附件；本地必须存在同名副本 + **sha256 留档可复验**）；
   **不得**以"仓库 zipball 即产物"替代；
3. **发布留档** `plan/RELEASE-M6.md`（**在 tag 之前写好并进 tag 树**）。

**另加**
* 发布前跑 `scripts/check_release.py` 无 FAIL；
* 提交面脱敏全 0（含 tag tagger 邮箱）；
* 命名：GitHub 仓库名 `session-to-regression`（本地目录保留日期标签 `10-17-session-to-regression`），署名 `yuluo554`；
* 发布物本体复核：**真下载 + 中立目录**解压跑 `s2r selftest`；附件与 tag 树逐字节同源；
* 隐私四层审计：源码 import / 发布产物扫描 / socket 拦截动态 / 加载面静态；
* topic 与 description 与 README 定位一致；
* tag 后事实（附件 sha256 / 下载复核）作为**追加提交**分栏记录。

**降级策略**：若 CI 首推出现环境差异型失败 → 修 CI 配置与测试环境依赖**不算动内核**；
失败原因与修复提交如实配对留档，"CI 绿"只记修复后的 run。

**命令**：`gh repo create yuluo554/session-to-regression --public` / `gh release create <tag> <zip> --notes-file ...`

**可演示物**：公开仓库 + Release 页面 + 一条"下载即用"的校验命令。
